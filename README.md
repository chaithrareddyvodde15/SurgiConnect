# SurgiConnect

SurgiConnect is a real-time emergency surgical coordination platform designed to connect hospital managers, doctors, and patients during critical medical situations.

## 🚀 Vision
To enable instant coordination of multi-specialist surgical teams during emergencies using real-time availability tracking.

## 🏥 Core Features
- Role-based authentication (Doctors, Managers, Patients)
- Live doctor availability tracking
- Emergency broadcast system
- Multi-specialist coordination
- Audit logs for legal tracking

## 🛠 Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express
- Database: MongoDB
- Real-time: Socket.io (Planned)

Currently under active development.
